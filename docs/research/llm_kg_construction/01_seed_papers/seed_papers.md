# Seed Papers

The seed set was chosen to cover the three decisions that dominate KnowAct authoring: what to extract, how to reconcile it, and how to verify it.

| ID | Paper | Why it is a seed |
|---|---|---|
| P001 | [Extract, Define, Canonicalize](https://aclanthology.org/2024.emnlp-main.548/) | Clean decomposition for open extraction and post-hoc schema control. |
| P003 | [PiVe](https://aclanthology.org/2024.findings-acl.400/) | Concrete iterative verifier pattern. |
| P004 | [SAC-KG](https://aclanthology.org/2024.acl-long.238/) | Generator--verifier--pruner architecture for precision-oriented domain KGs. |
| P005 | [KGGen](https://proceedings.neurips.cc/paper_files/paper/2025/hash/2b368455e832d2b1a60bcad8c4c6481f-Abstract-Conference.html) | Entity/relation separation and iterative resolution. |
| P008 | [GraphRefine](https://aclanthology.org/2026.acl-long.1353/) | Typed repair is safer than binary deletion. |
| P011 | [ACE](https://jedm.educationaldatamining.org/index.php/JEDM/article/view/737) | Direct precedent for expert-efficient educational prerequisite graphs. |
| P012 | [A Brief Introduction to Evidence-Centered Design](https://www.ets.org/research/policy_research_reports/publications/report/2003/hsgs.html) | Grounds mastery rubrics in assessment design rather than extraction rhetoric. |
