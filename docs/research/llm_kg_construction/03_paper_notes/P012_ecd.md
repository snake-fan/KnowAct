# P012 — [A Brief Introduction to Evidence-Centered Design](https://www.ets.org/research/policy_research_reports/publications/report/2003/hsgs.html)

**Mislevy, Almond, and Lukas, ETS Research Report 2003.**

## Problem

Assessment tasks and scores need an explicit argument connecting observations to claims about what a learner knows.

## Method

Evidence-centered design coordinates a student/competency model, an evidence model, and a task model.

## Evidence

ECD is a foundational assessment-design framework rather than a benchmarked KG extraction algorithm.

## Limitation

It does not determine which textbook concepts or graph edges an LLM should extract.

## KnowAct transfer

For every node, connect mastery claims to observable answer evidence and to diagnostic questions. Validate rubrics separately from source entailment.
