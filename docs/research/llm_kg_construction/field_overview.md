# Field Overview

The field map converges on a practical pattern: specification and schema control, local evidence-grounded extraction, global canonicalization, independent verification, typed repair, and human adjudication.

KnowAct adds an assessment-design layer. Its node rubrics and pedagogical relations need separate expert validity evidence rather than only text entailment.
