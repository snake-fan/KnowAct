# Supplementary Literature Artifacts

The canonical quality gate and counted literature pool are:

1. [`../01_scope_and_quality_gate.md`](../01_scope_and_quality_gate.md)
2. [`../02_reviewed_paper_pool.md`](../02_reviewed_paper_pool.md)

The artifacts in this directory preserve an earlier 14-paper focused map built with a separate
`D1`/`D2` reading-depth rubric. They are useful for paper-level synthesis, individual notes, and
interactive browsing, but they have not all been reconciled against the canonical `G1`–`G5` gate.

Do not add the focused-pool count to the canonical 41-paper count. A paper influences a canonical
method or empirical claim only after it appears in `../02_reviewed_paper_pool.md` with the required
venue, evidence, limitation, and design-use audit.

## Contents

- [`focused_pool_scope.md`](focused_pool_scope.md): the earlier focused-map scope and depth rubric.
- [`focused_paper_pool.md`](focused_paper_pool.md): 14-paper focused pool with transfer boundaries.
- [`focused_paper_notes/`](focused_paper_notes/): individual paper notes using local `P001`–`P014`
  identifiers.
- [`seed_papers.md`](seed_papers.md): search seeds and expansion logic.
- [`paper_matrix.md`](paper_matrix.md): paper-to-design matrix for the focused pool.
- [`field_overview.md`](field_overview.md) and
  [`field_research_map.md`](field_research_map.md): compact field synthesis.
- [`maps/`](maps/): problem, method, evidence, timeline, and gap maps.
- [`paper_reports.json`](paper_reports.json): machine-readable focused-paper reports.
- [`research_map.html`](research_map.html): standalone interactive visualization of that focused map.

The `P001`–`P014` identifiers are local to these supplementary artifacts and are not aliases for the
numeric rows in the canonical 41-paper pool.
