# Field Overview

Interactive knowledge-map reconstruction sits at the intersection of four mature but incomplete
traditions.

Knowledge tracing models sequential student evidence but normally predicts future item responses.
Computerized adaptive testing chooses informative items but assumes a calibrated item bank. Dynamic
LLM profiling maintains a user state in dialogue but rarely represents it over a scored concept graph.
Agent benchmarks evaluate interaction but usually score external task completion instead of recovery
of a hidden user state.

KnowAct's research opportunity is the missing composition: an agent must interpret open-ended evidence,
maintain an auditable full-graph belief state, actively choose a diagnostic question, and expose enough
process state to distinguish good reconstruction from lucky final guesses.

The focused literature does not yet justify deterministic graph propagation, multi-agent complexity,
or simulator-only validity. Those remain empirical questions rather than assumed method ingredients.
