# P011 — [SimulatorArena](https://aclanthology.org/2025.emnlp-main.1786/)

**Dou et al., EMNLP 2025. Reading depth: D1.**

## Contribution

Uses 909 annotated human–LLM conversations in math tutoring and document creation to test whether
simulators reproduce human messages and preserve human assistant rankings.

## KnowAct transfer

Validate both behavioral similarity and ranking agreement on a smaller human interaction subset before
generalizing simulator-only agent conclusions.

## Do not transfer

Reported agreement is task- and configuration-specific. It is evidence for a validation method, not a
certificate for arbitrary user simulators.
