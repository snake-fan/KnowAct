# Timeline Map

- **2015 — DKT:** establishes neural sequential knowledge tracing as a strong latent-state modeling
  direction.
- **2021 — BOBCAT:** learns adaptive question selection rather than relying only on fixed information
  heuristics.
- **2022 — pyKT:** demonstrates that protocol and preprocessing choices can reverse or inflate KT
  conclusions.
- **2023 — BigToM:** strengthens mental-state evaluation with causal templates and control conditions.
- **2024 — AgentBoard:** makes intermediate progress and trajectory analysis first-class agent metrics.
- **2025 — FACD:** emphasizes fast early-stage diagnosis; RAISE and RLPA make active profile acquisition
  and explicit profile rewards central; τ-bench and SimulatorArena strengthen interaction reliability
  and simulator validity.
- **2026 — LongTutor, ParLD, ScaffoldLM:** decompose long-term conversational diagnosis and make
  assessment-driven memory explicit.

The chronological pattern is a move from passive latent prediction toward explicit, inspectable,
interactive state management. KnowAct adds a scored graph-indexed target state and active diagnostic
questioning under a visibility boundary.
