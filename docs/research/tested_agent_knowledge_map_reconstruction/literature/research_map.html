How to read this map

Select a paper. The detail panel distinguishes its actual evidence from the design idea that transfers to KnowAct. A top-venue paper is not treated as automatic proof for a different task.

Central gap: none of these papers validates a complete agent that actively recovers ordinal user mastery over a public typed graph from open-ended questions. Graph-aware propagation is therefore a KnowAct hypothesis requiring no-graph, untyped-graph, and perturbed-graph controls.
