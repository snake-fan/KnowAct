# Seed Papers and Expansion Logic

The search began from four mechanism anchors and expanded by the missing decision each revealed.

| Seed | Why it is a seed | Expansion question |
|---|---|---|
| [Deep Knowledge Tracing](https://proceedings.neurips.cc/paper_files/paper/2015/hash/bac9162b47c56fc8a4d2a519803d51b3-Abstract.html) | sequential latent knowledge-state update | how should evaluation avoid knowledge-tracing protocol leakage? |
| [BOBCAT](https://www.ijcai.org/proceedings/2021/332) | learned adaptive question selection | what works in the cold-start and early-turn regime? |
| [LongTutor](https://aclanthology.org/2026.acl-long.1371/) | separates evidence acquisition, diagnosis, and action | how should open-ended evidence be interpreted and stored? |
| [SimulatorArena](https://aclanthology.org/2025.emnlp-main.1786/) | tests simulators against human interactions and rankings | how should KnowAct validate simulator-dependent conclusions? |

Expansion stopped when each required agent decision and each major validity threat had at least two
independent anchors. Papers that only repeated an existing message were left for Related Work rather
than promoted to the focused pool.
