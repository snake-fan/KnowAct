# Experiment 02: Simulator Human Validity

[中文](README.zh-CN.md)

## Purpose

This experiment collects held-out human answers and tests whether SAGE
Simulator answers preserve a participant's expressed mastery, misconception,
uncertainty, and ability boundary without leaking hidden benchmark state.

A downstream matched-agent study separately tests whether agent comparisons
made with SAGE agree with comparisons made with human users.
