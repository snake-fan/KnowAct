# 实验 02：Simulator 真人有效性

[English](README.md)

## 目的

本实验使用留出的真人回答，验证 SAGE Simulator 是否忠实表达参与者的知识水平、误解、不确定性与能力边界，同时避免泄漏隐藏状态。

实验进一步检验：以 Simulator 代替真人比较 Tested Agents 时，能否保持相同的效应方向与排序。
