\section{Introduction}

In collaborative interaction, the most informative action is often not an answer but a question. A tutor must locate the boundary of a learner's understanding; a research assistant must discover which assumptions its collaborator already accepts; a decision-support agent must identify which uncertainty is blocking progress. In each case, assistance depends on an internal estimate of the user and on choosing an action that improves that estimate.

This is more demanding than describing a mental state after the relevant evidence has been supplied. The agent must decide which uncertainty matters, acquire evidence under a budget, revise its estimate, and let that estimate change what it does next. User modeling is therefore part of the control loop, not merely an explanatory annotation attached to a completed dialogue.

Existing evaluations illuminate different parts of this problem but do not identify the full loop. Machine Theory-of-Mind (ToM) benchmarks ask models to infer beliefs, intentions, or emotions from fixed narratives and conversations \citep{le2019revisiting,gandhi2023bigtom,kim2023fantom,xu2024opentom,chen2024tombench}. Their controlled questions make inference measurable, yet the benchmark---not the tested model---chooses the evidence. The model is never accountable for asking an uninformative question or for failing to resolve an uncertainty.

Interactive social-agent environments restore action, but usually score a holistic outcome such as goal completion, persuasion, or task success \citep{zhou2024sotopia,mou2025agentsense,hwang2026infusing,wang2026tomelp,zhou2026tomswe}. Such outcomes intentionally combine user modeling with planning, domain competence, language generation, and strategy. A successful trajectory may therefore reflect an accurate user model, a strong generic policy, environmental shortcuts, or some combination of them. The inference--application gap observed in explicit ToM evaluation makes this ambiguity consequential \citep{gu2024simpletom}.

The resulting gap is one of \emph{measurement}, not simply coverage. Static tasks isolate inference by removing evidence acquisition; interactive tasks restore action but often make the latent user state unobservable to the evaluator. Neither setting directly tests whether an agent can improve an explicit user model by choosing what evidence to request.

We study the following question:

\begin{quote}
\emph{Can an agent actively infer a user's hidden knowledge state through limited natural-language interaction, and use that evolving estimate to choose subsequent diagnostic actions?}
\end{quote}

We call the target behavior \emph{functional ToM for knowledge-grounded interaction}. \emph{Functional} means that a user model earns credit through an infer--update--act loop, not through a verbal claim that the model understands the user. \emph{Knowledge-grounded} narrows the latent state to reviewed, diagnosable concepts. This operational definition does not assert a human-like cognitive mechanism; it identifies behavior that a useful user model should support.

A valid test of this behavior requires three commitments. First, the latent state must be explicit enough to score directly; otherwise task success cannot establish that the user was modeled accurately. Second, evidence must be selected under a finite budget; otherwise an agent need not prioritize uncertainty. Third, the interaction must be auditable; otherwise leakage, unsupported inference, or simulator artifacts can masquerade as diagnosis.

\knowact turns these commitments into a controlled benchmark. A public knowledge graph defines the shared hypothesis space, while a hidden user-specific map defines the target. The agent spends a fixed number of turns asking diagnostic questions, maintains a full-graph working estimate, and submits a mastery prediction for every node. The simulator can express partial knowledge and misconceptions, but receives hidden information only after the current question has been grounded. The final map is scored deterministically against the hidden map.

This design makes several competing explanations testable. Fixed and random policies reveal whether interaction alone is sufficient. Working-map and graph ablations test whether explicit state maintenance guides action. Simulator variations reveal whether rankings depend on one generative proxy. Evidence references distinguish accurate reconstruction supported by the dialogue from accurate guesses.

Our contributions are therefore methodological rather than empirical at this stage:
\begin{itemize}[leftmargin=1.5em]
    \item We formulate active knowledge-state diagnosis as an identifiable target for functional user modeling, separating reconstruction quality from downstream task success.
    \item We derive a benchmark design in which the public graph, hidden map, turn budget, and visibility boundary each control a specific alternative explanation for apparent success.
    \item We specify a validation protocol that separates adaptivity, explicit state maintenance, simulator dependence, and transfer to human interaction instead of collapsing them into one leaderboard score.
\end{itemize}

The present paper establishes the construct, artifacts, and tests needed to evaluate these claims. It does not yet provide the empirical evidence required to conclude that any agent exhibits the target behavior. That distinction is deliberate: \knowact is intended to make such a claim falsifiable before it is made.
